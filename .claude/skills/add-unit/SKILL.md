# add-unit：新增一個教材單元

本 skill 是 AGENTS.md §3 的執行步驟。規則以 AGENTS.md 為準；兩者不一致時以 AGENTS.md 為準並回報差異。

## 輸入

- 來源檔案（PDF、pptx、docx、圖片），可多份。
- 主題：使用者指定，或依內容判斷屬於哪個既有主題；都不符合時建立新主題。

## 步驟

1. **判斷來源類型**：課本／簡報／論文／講義／掃描檔（AGENTS.md §3.2）。多份來源時決定主要來源。
2. **決定主題**：讀 `site.json` 與各 `content/*/course.json`。需要新主題時依 §3.4 建立，`unit_label` 依來源設定（章／講／篇）。
3. **登錄並建立檔案**：在 `course.json` 加入單元，執行 `python tools/new_chapter.py <topic> <no>`。
4. **讀格式範例**：從一個既有單元讀一個編號小節與附錄（以 Grep 定位 `^## `，再用 offset 讀取）。
5. **讀來源**：
   - 先取得總頁數 P。
   - PDF 以 Read 的 `pages` 參數每次最多 20 頁、連續讀完；無法渲染頁面時用 `pypdf` 擷取文字，圖表再個別確認。
   - 每批記下：定義、結論、公式或論點、例子、圖表，以及推導或論證所依賴的假設。
6. **規劃小節**：依 §3.3 的骨架建議切成 3–8 節，列出每節對應的頁碼，確認 p.1–P 全部有歸屬。
7. **撰寫**：依 §4（骨架）、§5（元件）、§6（寫作規範）填寫範本。
   - 說明自行重寫；計算題數值重新計算；論文數字照原文並標表號。
   - 每節至少一個例題或練習；附錄自我測驗至少 5 題；術語列入名詞對照表。
8. **畫圖**（選用）：只為能幫助理解的內容畫圖。使用 `core.js` 與主題 `lib.js` 的函式（§7）；需要新的共用函式時只新增、不修改既有函式，並更新 AGENTS.md §7。刪除範本的 `f-example`。
9. **產生並檢視**：`python tools/build.py`，以 `python -m http.server -d docs 8000` 開啟該頁，確認圖都有畫出、互動控制可用、console 無錯誤。
10. **自我檢查與回報**：逐項確認 AGENTS.md §8；回報新增／修改的檔案、涵蓋頁碼（p.1–P）、待使用者確認的事項。
