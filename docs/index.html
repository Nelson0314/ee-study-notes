本站的頁面怎麼產生：
  • 每一章是一個 Markdown 檔（content/<課程>/chNN-<slug>.md），使用固定的章節骨架與元件。
  • tools/check.py 依 編寫規範 驗證結構，tools/build.py 產生全部頁面。
  • 新增一章只需：在 course.json 登錄 → 依範本撰寫 Markdown → 執行 build。
