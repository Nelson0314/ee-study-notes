第 2 章由半導體物理推導出 PN 接面的電流方程式。本章將二極體視為電路元件，建立不同精確度的模型，並以這些模型分析整流、穩壓、限幅、倍壓等電路。分析的核心問題是：二極體在某一輸入下處於導通或截止，以及兩種狀態的邊界發生在哪一個輸入值。

3.1理想二極體

1　單向元件的需求

電阻、電容、電感都是線性元件：電流方向反轉時，元件的行為以相同規則對稱地反轉。許多電路功能需要非對稱的行為，例如把交流轉成直流（手機充電器）、讓訊號只在某一範圍內通過、保護電路免受過大電壓。這些功能都需要一個「電流只能單向流動」的元件。

以電阻為參照：電阻的 I/V 特性是一條通過原點的直線，斜率為 1/R。若要求元件在一個方向呈現 R = 0（短路）、另一方向呈現 R = ∞（開路），其 I/V 特性就成為兩段折線，這就是理想二極體。

2　理想二極體的定義

狀態條件等效電路驗證一致性時檢查
導通（on）順偏短路（VD = 0）求出的 ID ≥ 0
截止（off）逆偏開路（ID = 0）求出的 VD ≤ 0
分析程序
  1. 假設二極體為導通或截止（依直覺選擇較可能的一種）。
  2. 以對應的等效電路（短路或開路）求解整個電路。
  3. 檢查結果：假設導通則需 ID ≥ 0；假設截止則需 VD ≤ 0。
  4. 若矛盾，改用另一種假設重新求解。
多個二極體的電路需逐一檢查每個二極體；最多需嘗試 2n 種組合，實際上通常可由電路結構排除大部分。
例題 3.1
電壓源 Vin 串聯理想二極體 D 與電阻 R = 1 kΩ，D 的陽極接 Vin 的正端。分別求 Vin = +2 V 與 −2 V 時的電流。
  • Vin = +2 V：假設 D 導通（短路），I = 2 V / 1 kΩ = 2 mA > 0，假設成立。
  • Vin = −2 V：若假設導通得 I = −2 mA < 0，矛盾；改假設截止，I = 0，VD = −2 V ≤ 0，成立。
電路的 I–Vin 關係因此為：Vin > 0 時 I = Vin/R，Vin < 0 時 I = 0。

3　應用：整流器（Rectifier）

將上述電路的輸入改為正弦波 Vin = Vp sin ωt，並取電阻上的電壓為輸出。正半週 D 導通，Vout = Vin；負半週 D 截止，Vout = 0。輸出只保留正半週，平均值不為零，這就是半波整流器（half-wave rectifier）。

整流輸出的平均值（理想模型）：

Vout,avg = 1T ∫0T/2 Vp sin ωt dt = Vpπ

此輸出仍隨時間大幅變化，不能直接作為直流電源。3.5.1 節加入電容使其平滑。

觀念說明：初始假設如何選
  • 先看電源要把電流往哪個方向推。若電源會把電流由陽極推向陰極，先假設導通；反之先假設截止。
  • 假設錯誤不會造成錯誤答案，只會在驗證步驟出現矛盾（例如求出負的 ID），此時換另一種假設即可。
  • 假設截止時，二極體兩端電壓 VD 仍然存在，只是沒有電流。求 VD 的方法是把二極體當成開路，求開路兩端的電壓差（陽極電位減陰極電位）。
練習 3.1
(a) 將例題 3.1 的二極體反接（陰極朝向 Vin 的正端），R = 2 kΩ。求 Vin = +3 V 與 −3 V 時的二極體電流與電壓。
  1. Vin = +3 V：電源將電流由陰極推向陽極，先假設截止。ID = 0，R 上無壓降，二極體兩端承受全部電源電壓，陽極電位比陰極低 3 V，VD = −3 V ≤ 0，假設成立。
  2. Vin = −3 V：電流方向改為由陽極流向陰極，假設導通。VD = 0，ID = 3 V / 2 kΩ = 1.5 mA > 0，假設成立。
(b) Vin 經 R = 1 kΩ 接到節點 X；理想二極體 D1（陽極在 X）由 X 接地；理想二極體 D2（陽極在 X）由 X 接到 +2 V 電池正端。求 Vin = 5 V 時的 VX 與各電流。
  1. D1 與 D2 的陽極都在 X。D1 陰極在 0 V，D2 陰極在 2 V，X 升高時 D1 先導通。
  2. 假設 D1 導通、D2 截止：VX = 0。
  3. 驗證 D2：VD2 = 0 − 2 = −2 V ≤ 0，截止成立。
  4. IR = (5 − 0)/1 k = 5 mA，全部流入 D1，ID1 = 5 mA > 0，成立。
(c) 半波整流器輸入 Vp = 10 V，求理想模型下的輸出峰值與平均值；改用定電壓模型（0.8 V）時峰值為何？
  1. 理想模型：峰值 10 V，平均值 Vp/π = 10/π ≈ 3.18 V。
  2. 定電壓模型：Vin 必須超過 0.8 V 二極體才導通，輸出峰值 10 − 0.8 = 9.2 V。

3.2PN 接面作為二極體

實際的 PN 接面遵循第 2 章的指數關係 ID = IS[exp(VD/VT) − 1]，順偏時須約 0.6～0.8 V 才有可觀電流。依所需精確度，有三種常用模型：

模型導通時截止時適用情況
理想二極體短路開路電路電壓遠大於 0.8 V，只需定性結果
定電壓模型（CVD）電壓源 VD,on開路大多數手算分析；本章主要使用
指數模型ID = IS[exp(VD/VT) − 1]，需迭代或數值求解電源電壓接近 VD,on，或需要準確電流
定電壓模型的判斷條件
在定電壓模型下，導通的條件改為「二極體兩端電壓會超過 VD,on」，截止的驗證改為 VD < VD,on，而不是 VD < 0。轉折點因此平移 VD,on。
例題 3.2
Vin 經 R1 = 1 kΩ 接到節點 X，X 經 R2 = 1 kΩ 接地，二極體 D（陽極在 X）也由 X 接地。以定電壓模型（0.8 V）求 Vin = 1 V 與 3 V 時的 VX。
  • D 截止時 VX = Vin R2/(R1 + R2) = Vin/2。D 導通的條件為 Vin/2 > 0.8 V，即 Vin > 1.6 V。
  • Vin = 1 V：VX = 0.5 V < 0.8 V，D 截止。
  • Vin = 3 V：D 導通，VX = 0.8 V。驗證：IR1 = (3 − 0.8)/1 k = 2.2 mA，IR2 = 0.8 mA，ID = 1.4 mA > 0，成立。
觀念說明：定電壓模型的等效電路
導通的二極體以一個 VD,on 的電壓源取代，正端在陽極。這個電壓源只能「吸收」順向電流，不能讓電流反向流動；若計算出反向電流，代表二極體實際上是截止的。因此 CVD 的二極體可理解為「理想二極體串聯一個 0.8 V 電池」。
練習 3.2
(a) 2 V 電源經 R = 1 kΩ 驅動二極體（IS = 2×10−16 A）。分別以定電壓模型與指數模型求電流。
  1. CVD：I = (2 − 0.8)/1 k = 1.2 mA。
  2. 指數模型迭代，以 1.2 mA 起算：VD = 0.026 ln(1.2×10−3/2×10−16) = 0.026 × 29.42 ≈ 0.765 V。
  3. I = (2 − 0.765)/1 k = 1.235 mA → VD = 0.026 ln(6.18×1012) ≈ 0.766 V → I ≈ 1.234 mA，已收斂。
  4. CVD 誤差約 3%。電源電壓為 VD,on 的 2.5 倍，CVD 已可接受。
(b) 同 (a) 但電源改為 1 V。CVD 的誤差變為多少？
  1. CVD：I = (1 − 0.8)/1 k = 0.2 mA。
  2. 指數模型：假設 VD = 0.73 V → I = 0.27 mA → VD = 0.026 ln(1.35×1012) ≈ 0.726 V → I = 0.274 mA → VD ≈ 0.727 V，收斂於 I ≈ 0.273 mA。
  3. CVD 誤差約 27%。電源電壓接近 VD,on 時，VD 的小誤差佔 R 上電壓的比例很大，必須使用指數模型。
(c) 例題 3.2 改為 R1 = 2 kΩ、R2 = 1 kΩ。求二極體開始導通的 Vin，以及 Vin = 3 V 時的 ID。
  1. 截止時 VX = Vin × 1/(2 + 1) = Vin/3。導通條件 Vin/3 > 0.8，即 Vin > 2.4 V。
  2. Vin = 3 V > 2.4 V，D 導通，VX = 0.8 V。
  3. IR1 = (3 − 0.8)/2 k = 1.1 mA，IR2 = 0.8/1 k = 0.8 mA。
  4. KCL：ID = 1.1 − 0.8 = 0.3 mA > 0，成立。

3.3其他例題：轉移特性

電路的輸入輸出特性（transfer characteristic）是把 Vout 畫成 Vin 的函數。對含二極體的電路，作法是：找出二極體狀態改變的轉折點 Vin 值，在轉折點兩側分別以對應的等效電路寫出 Vout。轉移特性一旦確定，任何輸入波形的輸出都可以逐點對照得到。

繪製轉移特性的步驟
  1. 令 Vin 為很負的值，判斷每個二極體的狀態，寫出 Vout 的表示式。
  2. 逐漸增加 Vin，找出某個二極體兩端電壓恰好等於 VD,on（CVD）或 0（理想）的時刻，該 Vin 即為轉折點。
  3. 在轉折點以上，以新的狀態重新寫出 Vout。
  4. 重複直到 Vin 很正。在轉折點處，兩側的 Vout 表示式必須相等（曲線連續），可用來檢查計算。
電路 A（並聯型，CVD）電路 B（串聯型，CVD）
轉折點Vin = VB + VD,onVin = VD,on
轉折點以下D 截止，Vout = Vin（斜率 1）D 截止，Vout = 0
轉折點以上D 導通，Vout = VB + VD,on（斜率 0）D 導通，Vout = Vin − VD,on（斜率 1）
例題 3.3：二極體與電阻並聯
Vin 經 R1 接到輸出，輸出端對地接 R2，且另有 D（陽極在輸出）串聯 VB 對地。CVD 下：
  • D 截止：Vout = Vin R2/(R1 + R2)，斜率為分壓比。
  • 轉折點：Vout = VB + VD,on，對應 Vin = (VB + VD,on)(1 + R1/R2)。
  • D 導通：Vout 固定於 VB + VD,on，斜率為 0。
定電壓模型下，導通的二極體使該節點電壓固定，因此導通後的斜率由「節點是否被電壓源固定」決定，與 R2 無關。
I/V 特性的另一種用法
除 Vout(Vin) 外，也常需要電路從輸入端看進去的 Iin(Vin) 特性。作法相同：在轉折點兩側分別求 Iin。例如電路 A 中，D 截止時 Iin = 0（輸出未接負載），D 導通後 Iin = (Vin − VB − VD,on)/R，斜率 1/R。
練習 3.3
(a) 電路 A，VB = 1.2 V，CVD。求轉折點，以及 Vin = −1 V、3 V 時的 Vout。
  1. 轉折點：Vout 到達 VB + VD,on = 2.0 V 時 D 開始導通，此時 R 上無電流，Vin = 2.0 V。
  2. Vin = −1 V < 2.0 V：D 截止，R 無電流，Vout = Vin = −1 V。
  3. Vin = 3 V > 2.0 V：D 導通，Vout = 2.0 V，R 上電流 (3 − 2)/1 k = 1 mA 流入 D。
(b) 電路 B，R = 1 kΩ，CVD。求 Vin = 0.5 V 與 2.5 V 時的 Vout 與電流。
  1. Vin = 0.5 V < 0.8 V：D 截止，I = 0，Vout = I·R = 0。驗證 VD = 0.5 V < 0.8 V。
  2. Vin = 2.5 V：D 導通，Vout = 2.5 − 0.8 = 1.7 V，I = 1.7 mA。
(c) 例題 3.3 中取 R1 = R2 = 1 kΩ、VB = 0.2 V。畫出轉移特性的轉折點與各段斜率，並求 Vin = 1 V、4 V 的輸出。
  1. D 截止：Vout = Vin/2，斜率 0.5。
  2. D 導通條件 Vout > 0.2 + 0.8 = 1.0 V，對應 Vin = 2.0 V。
  3. Vin > 2.0 V：Vout = 1.0 V，斜率 0。
  4. Vin = 1 V → 0.5 V；Vin = 4 V → 1.0 V（IR1 = 3 mA，IR2 = 1 mA，ID = 2 mA）。

3.4大信號與小信號操作

至此的分析都屬於大信號（large-signal）操作：輸入變化大到使二極體在導通與截止之間切換，必須使用非線性模型。另一類常見情況是二極體已偏壓在某一直流電流 ID，再疊加一個很小的變化量。此時只需關心工作點附近的局部行為，可以用線性的小信號（small-signal）模型處理。

1　小信號電阻 rd

在工作點 (VD1, ID1) 附近，以指數曲線的切線近似：

dIDdVD = ISVT expVD1VT = ID1VT
rd = VTID      ΔID = ΔVDrdID = 1 mA 時 rd = 26 Ω

rd 與偏壓電流成反比：偏壓電流越大，切線越陡，小信號電阻越小。rd 與 IS（面積）無關。

2　小信號近似的成立條件

精確的電流變化為 ΔID = ID1[exp(ΔVD/VT) − 1]。將指數展開：

ΔID = ID1 (ΔVDVT + 12(ΔVDVT)2 + ⋯)

只保留第一項即為小信號模型，條件為 |ΔVD| ≪ VT。相對誤差約為 ΔVD/(2VT)。

3　分析步驟

直流與小信號分開求解
  1. 直流分析：只保留直流源，以 CVD 或指數模型求出偏壓電流 ID。
  2. 計算 rd = VT/ID。
  3. 小信號分析：直流電壓源短路接地、直流電流源開路，二極體以 rd 取代，求出小信號輸出。
  4. 總輸出 = 直流輸出 + 小信號輸出。
例題 3.4
二極體偏壓於 ID = 1 mA，兩端電壓變化 ΔVD = 10 mV。小信號模型給出 ΔID = 10 mV / 26 Ω = 0.385 mA；精確值為 1 mA × [exp(10/26) − 1] = 0.469 mA，誤差約 18%。若 ΔVD = 2 mV，小信號 2/26 = 0.0769 mA，精確 1 × [exp(2/26) − 1] = 0.0800 mA，誤差約 4%。
觀念說明：為什麼要分成「直流」與「小信號」
二極體的 I/V 是曲線，曲線上不同位置的斜率不同。直流分析決定「站在曲線上的哪一點」，小信號分析則只看「在這一點附近稍微移動時，電流跟著變多少」。只要移動量很小，曲線在這一小段內幾乎是直線，就能用電阻 rd 代表，於是可以使用分壓、KCL 等線性電路的工具。若移動量大到跨越曲線上明顯彎曲的部分，這個近似就失效，必須回到指數模型。
練習 3.4
(a) 二極體偏壓於 0.5 mA，求 rd。若偏壓電流加倍，rd 如何變化？
  1. rd = VT/ID = 26 mV / 0.5 mA = 52 Ω。
  2. rd 與 ID 成反比，電流加倍為 1 mA 時 rd = 26 Ω，減半。
(b) 二極體偏壓於 2 mA，兩端電壓增加 3 mV，以小信號模型估計電流變化，並與精確值比較。
  1. rd = 26/2 = 13 Ω。
  2. 小信號：ΔI = 3 mV / 13 Ω ≈ 0.231 mA。
  3. 精確：ΔI = 2 mA × [exp(3/26) − 1] = 2 × 0.1223 ≈ 0.245 mA。
  4. 誤差約 6%，與估計式 ΔV/(2VT) = 3/52 ≈ 5.8% 一致。
(c) 1 V 直流源經 R = 1 kΩ 驅動一顆二極體，直流電流為 0.25 mA。若電源疊加 ±20 mV 的小訊號，二極體兩端的電壓變化為多少？
  1. rd = 26 mV / 0.25 mA = 104 Ω。
  2. 小信號等效電路：訊號源 → R → rd → 地，為分壓電路。
  3. ΔvD = ±20 mV × 104/(1000 + 104) ≈ ±1.9 mV。
  4. 檢查：1.9 mV ≪ 26 mV，小信號近似成立。

3.5二極體的應用

1　半波與全波整流

(a) 加上電容：峰值偵測器（peak detector）

在半波整流器的輸出端並聯電容 C。Vin 上升時 D 導通，C 被充電至輸入峰值；Vin 下降後 Vin < Vout + VD,on，D 截止，C 無放電路徑（無負載時），Vout 保持在峰值。這個電路稱為峰值偵測器。

接上負載 RL 後，D 截止期間 C 經由 RL 放電，Vout 以時間常數 RLC 指數下降，直到下一週期 Vin 再度超過 Vout + VD,on。輸出因此呈鋸齒狀，峰對峰變化量稱為漣波（ripple）VR。

觀念說明：一個週期內發生的事（含 RL）
  1. 充電：Vin 接近峰值、且 Vin − VD,on 高於電容電壓時，D 導通。電源同時供應負載電流並把 C 充到 Vin,p − VD,on。
  2. D 截止：Vin 越過峰值開始下降，Vin − VD,on 低於電容電壓，D 逆偏而截止。輸入端與輸出端此後互不相連。
  3. 放電：負載電流全部由 C 提供，Vout 逐漸下降。此時 Vin 的負半週對輸出沒有影響。
  4. 再次充電：下一個週期 Vin 上升到超過 Vout + VD,on 時，D 再度導通，回到步驟 1。
電容的角色是「蓄水池」：二極體在短時間內補充電荷，電容在其餘時間持續供應負載。

(b) 漣波電壓

若 RLC 遠大於輸入週期 Tin，放電近似線性，且放電時間近似一整個週期。放電電流約為 Vp/RL，因此：

VR ≈ VpRL · TinC = VpRLC finVp 為輸出峰值（CVD 下為 Vin,p − VD,on）

等價的說法：漣波 = 負載電流 × 放電時間 / 電容，即 VR ≈ ILTin/C。增大 C 可降低漣波，代價是電容體積與後述的峰值電流。

(c) 導通角與二極體峰值電流

D 只在每週期靠近峰值的短時間 Δt 內導通，在此期間補足一整個週期流失的電荷。由 Vp cos(ωΔt) = Vp − VR 及小角度近似：

ωΔt ≈ √2VRVp      Ip ≈ CωVp√2VRVp + VpRL

Ip 的第一項是電容的充電電流 C dVin/dt 在導通區間開始時的值，第二項是負載電流。漣波越小，導通區間越短，二極體必須在更短時間內提供相同電荷，峰值電流因此越大。

(d) 互動：整流器波形

(e) 峰值逆向電壓（PIV）

二極體截止時承受的最大逆向電壓須低於其崩潰電壓。

電路最嚴重時刻PIV（CVD）
半波，無電容Vin = −Vp，Vout = 0Vp
半波，含電容Vin = −Vp，Vout ≈ Vp − VD,on2Vp − VD,on
全波橋式截止的一對二極體各承受約輸出電壓加一個導通壓降Vp − VD,on

(f) 全波整流的比較

  • 輸出在每半週都被補充一次，放電時間減半，VR ≈ Vp/(2RLC fin)。相同漣波下電容可減半。
  • 代價是導通路徑上有兩顆二極體，輸出峰值為 Vin,p − 2VD,on，在低壓電源中這 1.6 V 的損失比例很大。
  • 橋式電路的負載兩端都不接地（相對於輸入源），使用時需注意參考點。
例題 3.5：電容設計
Vin,p = 5 V、fin = 60 Hz、RL = 1 kΩ，要求 VR ≤ 0.1 V。
  • 半波：Vp = 4.2 V，C ≥ 4.2 / (1 kΩ × 60 × 0.1) = 700 µF。ωΔt ≈ √(0.2/4.2) = 0.218 rad，Δt ≈ 0.58 ms。Ip ≈ 700 µF × 377 × 4.2 × 0.218 + 4.2 mA ≈ 0.246 A。PIV ≈ 9.2 V。
  • 全波橋式：Vp = 3.4 V，C ≥ 3.4 / (1 kΩ × 120 × 0.1) ≈ 283 µF。PIV ≈ 4.2 V。
負載平均電流僅約 4 mA，二極體峰值電流卻約為其 60 倍，二極體的電流額定值須依峰值選擇。
練習 3.5A（整流）
(a) 半波整流，Vin,p = 12 V，fin = 60 Hz，RL = 200 Ω，要求 VR ≤ 0.5 V。求最小 C。
  1. 輸出峰值 Vp = 12 − 0.8 = 11.2 V。
  2. 由 VR = Vp/(RLC fin) 解出 C = Vp/(RL fin VR) = 11.2/(200 × 60 × 0.5) ≈ 1.87 mF。
(b) 承 (a)，求導通時間 Δt 與二極體峰值電流。
  1. ωΔt ≈ √(2VR/Vp) = √(1/11.2) ≈ 0.299 rad。
  2. ω = 2π × 60 ≈ 377 rad/s，Δt ≈ 0.299/377 ≈ 0.79 ms（週期 16.7 ms 中只導通約 5%）。
  3. Ip ≈ CωVp × 0.299 + Vp/RL = 1.87×10−3 × 377 × 11.2 × 0.299 + 11.2/200 ≈ 2.36 + 0.056 ≈ 2.4 A。
  4. 平均負載電流約 56 mA，峰值電流約為其 43 倍。
(c) 承 (a) 改用橋式全波整流，最小 C 為何？PIV 為何？
  1. 輸出峰值 Vp = 12 − 1.6 = 10.4 V。
  2. 放電間隔減半：C = Vp/(2RL fin VR) = 10.4/(2 × 200 × 60 × 0.5) ≈ 867 µF。
  3. PIV ≈ Vin,p − VD,on = 11.2 V；半波含電容時則為 2 × 12 − 0.8 = 23.2 V。
(d) 觀念題：若把 RL 拿掉（無負載），含電容的半波整流器輸出為何？漣波為何？
  1. 無負載時電容沒有放電路徑，第一個峰值後 Vout 保持在 Vin,p − VD,on。
  2. 漣波為 0，對應公式中 RL → ∞。此即峰值偵測器。

2　穩壓（Voltage Regulation）

整流器的輸出含漣波，且隨負載電流變化。穩壓器的目的是使輸出對輸入變化與負載變化都不敏感。利用二極體「電流變化大、電壓變化小」的特性，可構成簡單的穩壓器：電源經電阻 R 供應數個串聯的順偏二極體，輸出取自二極體串兩端。

ΔVoutΔVin = 3rdR + 3rd      ΔVout = −ΔIL · (3rd ∥ R)
例題 3.6
Vin = 5 V 含 ±0.1 V 漣波，R = 1 kΩ，三顆二極體 IS = 5×10−16 A。
  1. 直流（迭代）：假設 VD = 0.75 V → I = (5 − 2.25)/1 k = 2.75 mA → VD = VT ln(2.75 mA/IS) = 0.763 V → I = 2.71 mA → VD = 0.762 V，收斂。Vout ≈ 2.29 V，ID ≈ 2.71 mA。
  2. rd = 26 mV / 2.71 mA ≈ 9.6 Ω，3rd ≈ 28.8 Ω。
  3. 輸出漣波：±0.1 V × 28.8/(1000 + 28.8) ≈ ±2.8 mV，衰減約 36 倍。
  4. 若負載自輸出抽取 0.5 mA：ΔVout ≈ −0.5 mA × (28.8 ∥ 1000 Ω) ≈ −14 mV。此時 ID 降為約 2.2 mA，ΔIL 相對 ID 不算很小，小信號結果只是估計值。
降低 3rd/R 可改善穩壓，但增加偏壓電流會提高功耗。輸出電壓只能是 VD,on 的整數倍左右，需要其他電壓時改用齊納二極體（崩潰區的電壓近似固定）。
觀念說明：為什麼二極體能穩壓
電阻 R 的 I/V 為直線：電壓變 10%，電流也變 10%。二極體則相反：電流變 10%，電壓只變 VT ln 1.1 ≈ 2.5 mV。輸入電壓的變化大部分落在 R 上（改變了電流），而二極體串兩端的電壓幾乎不動。小信號模型把這件事量化為 R 與 nrd 的分壓：rd 很小，分到的比例就很小。
練習 3.5B（穩壓）
(a) Vin = 3 V 含 ±0.2 V 漣波，R = 500 Ω，兩顆二極體串聯。以 CVD 求直流電流，再求輸出漣波。
  1. 直流：ID ≈ (3 − 2 × 0.8)/500 = 2.8 mA。
  2. rd = 26/2.8 ≈ 9.3 Ω，2rd ≈ 18.6 Ω。
  3. 小信號電路：漣波源 → R → 2rd → 地。ΔVout = ±0.2 × 18.6/(500 + 18.6) ≈ ±7.2 mV。
(b) 承 (a)，若要求輸出漣波降為一半，R 與偏壓電流應如何調整（Vin 不變）？
  1. 輸出漣波 ≈ ΔVin × 2rd/R（R ≫ 2rd）。
  2. rd = VT/ID，而 ID ≈ (Vin − 1.6)/R，因此 2rd/R ≈ 2VT/(Vin − 1.6)，與 R 無關。
  3. 結論：在 Vin 固定時，單純改 R 幾乎不改善漣波抑制比；需要提高 Vin − nVD,on，或改用其他穩壓架構。

3　限幅電路（Limiting Circuits）

限幅器（limiter）在輸入位於某範圍內時使輸出等於輸入（斜率 1），超出範圍時使輸出固定於上限或下限。用途包括保護後級電路的輸入端，避免過大電壓造成損壞。3.3 節的電路 A 就是單邊限幅器；加入第二個反向的二極體與電池即構成雙邊限幅器。

注意
實際二極體以指數模型描述時，轉折點附近並非銳利折角，輸出在接近限幅值前就開始被壓縮。若要求限幅器對範圍內的訊號完全不產生失真，輸入幅度需與轉折點保持數個 VT 以上的距離。
練習 3.5C（限幅）
(a) 設計雙邊限幅器，使輸出限制在 −1.5 V 到 +2 V（VD,on = 0.8 V）。求 VB1、VB2。
  1. 上限 VB1 + 0.8 = 2 → VB1 = 1.2 V。
  2. 下限 −(VB2 + 0.8) = −1.5 → VB2 = 0.7 V。
(b) 承 (a)，輸入 Vin = 3 sin ωt，畫出輸出波形的特徵值；Vin = 1 V 時 R 上的電流為何？
  1. 輸出在 Vin > 2 V 時被截為 2 V，在 Vin < −1.5 V 時被截為 −1.5 V，其餘時間 Vout = Vin。
  2. Vin = 1 V 落在 −1.5～2 V 範圍內，兩顆二極體皆截止，R 上電流為 0（輸出未接負載）。
(c) 若把 D1 支路的電池拿掉（VB1 = 0），正半週的輸出上限為何？
  1. 上限變為 0 + VD,on = 0.8 V。這是最簡單的保護電路：以一顆順偏二極體限制輸入不超過約 0.8 V。

4　倍壓器（Voltage Doubler）

某些應用需要高於輸入峰值的直流電壓。倍壓器由兩部分組成：

  1. 箝位器（clamp）：C1 與 D1。負半週 D1 導通，將 C1 充電至 Vp（左正右負的相反極性，使 VX 最低為 0）。之後 VX = Vin + Vp，波形整體上移 Vp，範圍 0～2Vp。
  2. 峰值偵測器：D2 與 C2，偵測 VX 的峰值 2Vp。

以定電壓模型，VX 的最低值為 −VD,on，最高值為 2Vp − VD,on，輸出為 2Vp − 2VD,on。接上負載時，輸出同樣出現漣波，分析方式與峰值偵測器相同。

補充
重複「箝位 + 峰值偵測」的結構可串接成三倍、四倍壓器，常用於需要高電壓但電流很小的場合。
觀念說明：電容兩端電壓不能瞬間改變
箝位器的關鍵是電容。C1 充電完成後，兩端電壓固定為 Vp（無放電路徑）。電容可視為一個串在訊號路徑上的電池：VX = Vin + Vp，輸入波形的形狀不變，只是整體上移。D1 的作用是決定這顆「電池」的電壓：它使 VX 的最低點恰好被限制在 0 V（CVD 下為 −VD,on）。
練習 3.5D（倍壓）
(a) 倍壓器 Vin,p = 3 V，CVD。求 VX 的範圍與無負載輸出。
  1. 負半週峰值 Vin = −3 V 時 D1 導通，VX = −0.8 V，C1 兩端電壓 = VX − Vin = 2.2 V（右端較高）。
  2. VX = Vin + 2.2 V，範圍 −0.8 V 到 5.2 V。
  3. 峰值偵測：Vout = 5.2 − 0.8 = 4.4 V = 2Vp − 2VD,on。
(b) 為何互動圖中 Vout 需要多個週期才接近 2Vp？
  1. D2 導通時，C1 與 C2 串在同一路徑上分享電荷，C1 的電壓會因此下降一些。
  2. 下一個負半週 D1 把 C1 重新充回 Vp，正半週再把部分電荷送到 C2。
  3. 每次送出的量與「VX 峰值 − Vout」成正比，因此 Vout 以遞減的步幅逼近 2Vp。

5　準位移位與開關

(a) 準位移位器（Level Shifter）

兩個電路的直流準位不同時，需要將訊號的直流值平移而不改變其交流成分。將偏壓於固定電流的二極體串在訊號路徑上，輸出即為輸入減去 VD,on（或其整數倍）。由小信號觀點，二極體只呈現很小的 rd，訊號的變化量幾乎完整傳到輸出。此作法的限制是平移量只能約為 VD,on 的整數倍，且偏壓電流必須維持，否則 VD 隨電流改變。

(b) 二極體作為開關

以控制電壓決定二極體導通或截止，可使訊號路徑接通或斷開。例如取樣電路中，二極體導通時電容追隨輸入，截止時電容保持取樣值。問題在於：導通時的訊號路徑上存在 VD,on 的壓降，且壓降隨電流變化，使取樣值產生誤差；同時二極體只能單向導電，電容無法經由同一二極體放電。這些限制使二極體開關在積體電路中多被 MOS 開關取代（第 6、7 章）。

B　常見陷阱

易錯處
  1. 假設後未驗證：假設導通後必須檢查 ID 方向，假設截止後必須檢查 VD。只求解不驗證可能得到物理上不可能的答案。
  2. CVD 的截止條件：是 VD < VD,on，不是 VD < 0。
  3. 漣波公式中的 Vp：是輸出峰值（扣除二極體壓降），橋式需扣兩個壓降。
  4. 全波的頻率：放電間隔為 Tin/2，公式中的 fin 要乘 2。
  5. 小信號分析時的直流源：直流電壓源視為短路，而不是保留其電壓值；rd 取代二極體時不再串聯 VD,on。
  6. rd 由偏壓電流決定：必須先完成直流分析，不能直接用 1 mA 對應的 26 Ω。
  7. PIV 與電容：加入濾波電容後，半波整流的 PIV 由 Vp 增為約 2Vp。

C　自我測驗

1. 半波整流含電容，Vin,p = 10 V，VD,on = 0.8 V，RL = 500 Ω，C = 1000 µF，fin = 60 Hz。求漣波。Vp = 9.2 V，VR ≈ 9.2/(500 × 10−3 × 60) ≈ 0.31 V
2. 同第 1 題改為橋式全波整流，求漣波。Vp = 8.4 V，VR ≈ 8.4/(500 × 10−3 × 120) = 0.14 V
3. 二極體偏壓於 2 mA，求 rd。rd = 26 mV / 2 mA = 13 Ω
4. 雙邊限幅器 VB1 = 1 V、VB2 = 2 V、VD,on = 0.8 V，求輸出範圍。−2.8 V ≤ Vout ≤ 1.8 V
5. 第 1 題電路中二極體的 PIV 約為多少？2Vin,p − VD,on = 19.2 V
6. 倍壓器 Vin,p = 5 V，以定電壓模型求無負載輸出。2 × 5 − 2 × 0.8 = 8.4 V
7. 為何降低漣波會提高二極體峰值電流？漣波越小，每週期二極體導通的時間越短（ωΔt ≈ √(2VR/Vp)），但需補充的電荷（約 ILTin）不變，因此電流峰值增加。
8. 例題 3.6 的穩壓器若改用四顆二極體（其餘不變），輸出漣波如何變化？Vout 約 3.0 V，ID ≈ (5 − 3.0)/1 k ≈ 2.0 mA，rd ≈ 13 Ω，4rd ≈ 52 Ω，ΔVout ≈ ±0.1 × 52/1052 ≈ ±4.9 mV，漣波變大：串聯顆數增加且偏壓電流下降，兩者都使 nrd 增大。
9. 電路 B（串聯型）以理想模型與定電壓模型分析，轉移特性有何差別？理想模型轉折點在 Vin = 0，導通後 Vout = Vin；定電壓模型轉折點右移至 0.8 V，導通後 Vout = Vin − 0.8 V。兩者斜率相同，僅平移。
