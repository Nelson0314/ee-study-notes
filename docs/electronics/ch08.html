8.1運算放大器的基本模型

1　差動放大與增益

運算放大器有兩個輸入端、一個輸出端，放大的是兩輸入端的電壓差。以非反相輸入（noninverting input，標「+」）電壓 Vin1、反相輸入（inverting input，標「−」）電壓 Vin2 表示：

Vout = A0(Vin1 − Vin2)

A0 稱為開迴路增益（open-loop gain），一般為 103～106。增益常以分貝表示：|A|dB = 20 log|A|。兩輸入端電壓的差值稱為差模（differential mode）信號，兩者的平均值稱為共模（common mode）信號；理想 op amp 只放大差模信號。

把其中一個輸入端接地，即可得到兩種極性的放大：反相端接地時 Vout = A0Vin1，增益為正；非反相端接地時 Vout = −A0Vin2，增益為負。

2　四種放大器型態

依輸入、輸出量是電壓或電流，放大器分成四類。理想的輸入／輸出阻抗由「不影響前級、不受負載影響」決定：量電壓的輸入端要高阻抗，量電流的輸入端要低阻抗；輸出電壓的一端要低阻抗，輸出電流的一端要高阻抗。

型態增益單位理想輸入阻抗理想輸出阻抗典型實例
電壓放大器（V/V）V/V大小運算放大器
轉導放大器（transconductance, V/I）A/V大大單一電晶體
電流放大器（I/I）A/A小大電流鏡
轉阻放大器（transimpedance, I/V）V/A小小光二極體接收電路

3　理想 op amp 與直流設計指標

理想 op amp 具備：輸入阻抗無窮大、輸出阻抗為零、增益與頻寬無窮大，且功耗低。實際設計時另有幾項直流指標：

  • 輸入共模範圍（input common-mode range）：輸入共模電壓在此範圍內，內部電晶體都維持在放大所需的工作區。
  • 輸出擺幅（output swing）：輸出電壓能到達、且增益不明顯下降的範圍。
  • 直流偏移電壓（DC offset voltage）：輸入差為零時輸出仍不為零；等效為一個串在輸入端的小電壓源，8.5 節討論。

4　虛短路

把輸出直接接回反相端（Vin2 = Vout），由 Vout = A0(Vin − Vout) 得

Vout/Vin = A01 + A0

A0 → ∞ 時 Vout → Vin，兩輸入端電壓相等但兩端之間沒有電流流過，稱為虛短路（virtual short）。虛短路只在負回授存在、且 op amp 未飽和時成立。這個電路的閉迴路增益（closed-loop gain）為 1，稱為電壓隨耦器（voltage follower）或單位增益緩衝器（unity-gain buffer）。

觀念說明：分析 op amp 電路的兩條規則
理想 op amp 加上負回授時，分析只需要兩個條件：
  1. 虛短路：V+ = V−（因 A0 無窮大，有限輸出對應的輸入差為零）。
  2. 輸入端無電流：流入 + 端與 − 端的電流皆為零（因輸入阻抗無窮大）。
其餘部分以 KCL 在反相輸入節點列方程式即可。
例題 8.1
電壓隨耦器使用 A0 = 500 的 op amp，求閉迴路增益與相對誤差。
  • Vout/Vin = 500/501 ≈ 0.998。
  • 相對誤差 = 1 − 0.998 = 1/501 ≈ 0.2%。A0 越大，隨耦器越接近理想。
練習 8.1
（計算）op amp 的開迴路增益為 100 dB，換算成 V/V 是多少？
  1. 20 log A0 = 100 → log A0 = 5。
  2. A0 = 105 V/V。
（是非）只要 op amp 的增益很大，任何接法下兩輸入端電壓都會相等。
  1. ✗。虛短路需要負回授把輸出拉回反相端；開迴路或正回授時輸出會飽和，兩輸入端電壓可以相差很大（例如比較器）。

8.2非反相與反相放大器

1　非反相放大器

非反相放大器（noninverting amplifier）把輸出經分壓器 R1、R2 送回反相端，輸入加在非反相端。反相端電壓為 VoutR2/(R1 + R2)，由虛短路令其等於 Vin：

Vout/Vin = 1 + R1/R2

增益只由電阻比值決定。積體電路中電阻的絕對值誤差可達 ±20%，比值誤差卻可小於 0.1%，因此回授放大器的增益可以很精確。

兩個極端情形：R2 = 0 時（反相端接地）回授消失，增益等於 op amp 本身的 A0；R2 = ∞（或 R1 = 0）時電路變成電壓隨耦器，增益為 1。

2　有限 A0 造成的增益誤差

保留 A0：(Vin − VoutR2/(R1 + R2))A0 = Vout，整理得

VoutVin = 1R2R1 + R2 + 1A0 ≈ (1 + R1R2)[1 − (1 + R1R2)1A0]

近似式成立於 (1 + R1/R2) ≪ A0。相對增益誤差約為 (1 + R1/R2)/A0：閉迴路增益越大，誤差越大。要做高增益又要精確，op amp 的 A0 必須更大。

例題 8.2
非反相放大器 R1 = 9 kΩ、R2 = 1 kΩ。分別求 A0 = 1000 與 104 時的實際增益與誤差。
  • 理想增益 1 + 9 = 10；R2/(R1 + R2) = 0.1。
  • A0 = 1000：1/(0.1 + 0.001) ≈ 9.901，誤差 ≈ 0.99%。
  • A0 = 104：1/(0.1 + 0.0001) ≈ 9.990，誤差 ≈ 0.10%。A0 增加 10 倍，誤差降為 1/10。

3　反相放大器

反相放大器（inverting amplifier）的非反相端接地，虛短路使反相端成為虛接地（virtual ground）。流過 R2 的電流 Vin/R2 全部流經 R1：

Vout/Vin = −R1/R2

輸入阻抗為 Vin/Iin = R2，這是反相放大器與非反相放大器（輸入阻抗趨近無窮大）的主要差別。保留 A0 時，反相端電壓 VX = −Vout/A0，在該節點列 KCL 得

VoutVin = −R1/R21 + (1 + R1/R2)/A0

相對誤差同樣約為 (1 + R1/R2)/A0。

4　一般阻抗與 T 型回授網路

R1、R2 換成一般阻抗 Z1、Z2 時推導不變：反相組態 Vout/Vin = −Z1/Z2，非反相組態 Vout/Vin = 1 + Z1/Z2。8.3 節的積分器與微分器即為此形式的特例。

例題 8.3（T 型回授網路）
反相放大器的回授路徑改為 T 型網路：輸入電阻 R1 接到反相端，反相端經 R2 到節點 X，X 經 R3 接地、經 R4 接到輸出。求 Vout/Vin，並代入 R1 = 10 kΩ、R2 = R4 = 100 kΩ、R3 = 1 kΩ。
  • 反相端為虛接地，R1 與 R2 電流相同：VX = −(R2/R1)Vin。
  • 節點 X 的 KCL：(0 − VX)/R2 + (0 − VX)/R3 = (VX − Vout)/R4，得 Vout = VX(1 + R4/R2 + R4/R3)。
  • Vout/Vin = −(R2/R1)(1 + R4/R2 + R4/R3) = −10 × (1 + 1 + 100) = −1020。
  • 用單純反相放大器得到 −1020 需要 10.2 MΩ 的回授電阻；T 型網路只用到 100 kΩ，同時保持 10 kΩ 的輸入阻抗。
練習 8.2
（計算）反相放大器 R2 = 1 kΩ、R1 = 10 kΩ、A0 = 2000，求實際增益、相對誤差與輸入阻抗。
  1. 理想增益 −10；1 + R1/R2 = 11。
  2. Vout/Vin = −10/(1 + 11/2000) = −10/1.0055 ≈ −9.945，誤差 ≈ 0.55%。
  3. 輸入阻抗 = R2 = 1 kΩ。
（設計）以 1.2 V 參考電壓與非反相放大器產生 3.3 V 輸出，R1/R2 應為多少？
  1. 1 + R1/R2 = 3.3/1.2 = 2.75。
  2. R1/R2 = 1.75，例如 R1 = 17.5 kΩ、R2 = 10 kΩ。

8.3積分器與微分器

1　積分器

反相放大器的回授電阻換成電容 C1，Z1 = 1/(C1s)、Z2 = R1：

VoutVin = −1R1C1s　⟺　Vout = −1R1C1∫Vin dt

時域推導：虛接地使 R1 電流為 Vin/R1，此電流全部流入 C1，因此 C1dVout/dt = −Vin/R1。輸入為高度 V1、寬度 Tb 的脈波（C1 初始電壓為零）時，輸出在 0 < t < Tb 期間為斜率 −V1/(R1C1) 的直線，脈波結束後維持在 −V1Tb/(R1C1)。

RC 低通濾波器是積分器的被動近似：時間常數遠大於觀察時間時，電容電壓仍接近起始段的直線，但隨時間逐漸偏離（指數趨近）。op amp 的虛接地使電阻電流不受輸出電壓影響，因此能維持線性斜坡。

2　有限增益：有損積分器

A0 有限時，VX = −Vout/A0，推導得

VoutVin = −11A0 + (1 + 1A0)R1C1s

極點由原點移到 s = −1/[(1 + A0)R1C1]，稱為有損積分器（lossy integrator）。它等效於電容放大 (1 + A0) 倍的 RC 低通電路，低頻增益被限制在 A0，不再趨近無窮大。

3　微分器

電容與電阻互換位置（C1 在輸入、R1 在回授）：

VoutVin = −R1C1s　⟺　Vout = −R1C1dVindt

電容電流 C1dVin/dt 全部流過 R1 產生輸出。脈波輸入時，輸出只在上升緣與下降緣出現極窄的脈衝（理想上為 δ 函數），平坦段輸出為零。RC 高通濾波器是其被動近似，時間常數越小越接近微分器。

A0 有限時，轉移函數為 −R1C1s/[1 + (1 + R1C1s)/A0]：原點的零點保留，另外在 s = −(1 + A0)/(R1C1) 出現一個極點，稱為有損微分器，等效於電阻縮小 (1 + A0) 倍的 RC 高通電路。

易錯處
  1. 微分器對高頻雜訊的增益與頻率成正比，實務上很少直接使用。
  2. 非反相組態的增益為 1 + Z1/Z2，多出的「1」使它無法成為理想積分器或微分器；積分器與微分器一律使用反相組態。
例題 8.4
積分器 R1C1 = 10 µs、A0 = 1000。求有損積分器的極點頻率。
  • |p| = 1/[(1 + 1000) × 10 µs] ≈ 99.9 rad/s。
  • fp = 99.9/(2π) ≈ 15.9 Hz。輸入頻率遠高於 15.9 Hz 時，電路才表現為積分器。
練習 8.3
（計算）微分器 R1 = 10 kΩ、C1 = 10 nF，輸入為斜率 1 V/ms 的斜坡，求輸出。
  1. R1C1 = 100 µs；dVin/dt = 1000 V/s。
  2. Vout = −100 × 10−6 × 1000 = −0.1 V（定值）。
（計算）圖中的積分器若 Tb 改為 80 µs，脈波結束後輸出是多少？
  1. Vout = −V1Tb/(R1C1) = −0.1 × 80/10。
  2. = −0.8 V。

8.4差動、儀表、加法放大器與精密整流

1　差動放大器

差動放大器（difference amplifier）由反相與非反相放大器疊加而成：V1 經 R1 進入反相端，R2 為回授；V2 經 R3、R4 分壓後進入非反相端。

Vout = (1 + R2R1)R4R3 + R4V2 − R2R1V1

令共模輸入（V1 = V2）時輸出為零，需 R4/R3 = R2/R1；此時 Vout = (R2/R1)(V2 − V1)。電阻比值不匹配時共模信號會漏到輸出。

輸入阻抗：R3 = R1、R4 = R2 時，V2 端看到 R1 + R2，V1 端看到的阻抗與 V2 有關，量級為 R1。若為了提高增益 R2/R1 而縮小 R1，輸入阻抗隨之降低，不適合作為電壓放大器。

2　儀表放大器

儀表放大器（instrumentation amplifier）在差動放大器的兩個輸入前各加一級電壓隨耦器（或非反相放大器），使兩輸入端都呈現極高的輸入阻抗，增益則由後級的電阻比決定，兩者不再互相牽制。

3　加法器

反相放大器的反相端接上多個輸入電阻，各輸入的電流在虛接地匯合後流經回授電阻 RF：

Vout = −RF(V1R1 + V2R2)

R1 = R2 = R 時 Vout = −(RF/R)(V1 + V2)；各電阻不同時為加權加法器（weighted summer）。將部分輸入送入非反相端，即可同時做加法與減法，例如 v0 = v1k1 + v2k2 − v3Rc/R3 − v4Rc/R4，其中正號項的係數 k 由非反相端的分壓比與 (1 + Rc/Rb) 決定。

4　應用：電壓穩壓器

系統中不同元件需要不同的電源電壓（例如機器人的馬達、感測器、處理器）。電壓穩壓器（voltage regulator）在負載電流變化時仍輸出接近定值的電壓；常見架構是以非反相放大器放大一個精確的參考電壓：Vout = (1 + R1/R2)VREF，op amp 的低輸出阻抗使輸出不隨負載改變。

5　精密整流器

第 3 章的二極體整流器在 |Vin| < VD,on 時沒有輸出，無法處理小信號。精密整流器（precision rectifier）把二極體放進 op amp 的回授迴路：

  • Vin > 0：op amp 輸出 VY 升高使二極體導通，迴路閉合，虛短路使 Vout = Vin；op amp 輸出自動比 Vout 高出 VD,on。
  • Vin < 0：op amp 輸出往負飽和，二極體截止，Vout 經負載拉到 0。

等效上，二極體的導通電壓被除以 A0：只要輸入超過約 VD,on/A0，電路即可整流。反相型精密整流器在 Vin > 0 時二極體導通，VY 被釘在約 −VD,on、反相端為虛接地；Vin < 0 時二極體截止，VY 往正飽和，反相端電壓等於 Vin。

例題 8.5
差動放大器 R1 = R3 = 10 kΩ、R2 = R4 = 50 kΩ，V2 = 1.02 V、V1 = 1.00 V。求 Vout。若 R4 誤差 +2%（51 kΩ），共模增益為何？
  • 匹配時 Vout = 5 × (1.02 − 1.00) = 0.1 V。
  • R4 = 51 kΩ，V1 = V2 = Vc：Vout = Vc[6 × 51/61 − 5] ≈ 0.0164Vc。
  • 2% 的電阻誤差使共模增益由 0 變成約 0.016；Vc = 1 V 時輸出多出 16 mV，與 0.1 V 的有用信號相比已不可忽略。
練習 8.4
（計算）加法器 RF = 20 kΩ、R1 = 10 kΩ、R2 = 20 kΩ，V1 = 0.5 V、V2 = −0.3 V，求 Vout。
  1. Vout = −(2 × 0.5 + 1 × (−0.3))。
  2. = −0.7 V。
（計算）精密整流器使用 A0 = 104 的 op amp 與 VD,on = 0.7 V 的二極體，可整流的最小輸入約為多少？
  1. Vmin ≈ VD,on/A0 = 0.7/104。
  2. = 70 µV，遠小於一般二極體整流的 0.7 V。

8.5非理想效應：偏移電壓與輸入偏壓電流

1　直流偏移

輸入級元件不匹配使 op amp 在輸入差為零時輸出不為零，輸入輸出特性曲線整體向左或向右平移。這個效應以串接在輸入端的偏移電壓 Vos 表示，其大小與極性隨製程與溫度變化，只能給出統計範圍。

偏移與信號一起被放大。非反相放大器的輸出為

Vout = (1 + R1/R2)(Vin + Vos)

多級直接耦合時，前級輸出的偏移再被後級放大，可能使後級飽和。

2　積分器的偏移

積分器把 Vos 視為定值輸入持續積分：Vout ≈ Vos + Vost/(R1C1)，經過一段時間必然飽和。在 C1 兩端並聯電阻 R2 可提供直流回授路徑：

VoutVin = −R2/R1R2C1s + 1，直流輸出偏移 = (1 + R2/R1)Vos

代價是極點不在原點，電路只在 ω ≫ 1/(R2C1) 時表現為積分器。

3　輸入偏壓電流

以 BJT 為輸入級的 op amp，兩輸入端需要直流基極電流 IB1（+ 端）、IB2（− 端），稱為輸入偏壓電流（input bias current）。以非反相放大器、Vin = 0 為例：+ 端為 0 V，虛短路使 − 端也為 0 V，R2 上沒有電流，因此 IB2 全部由輸出經 R1 提供：

Vout = R1IB2

IB1 從接地的信號源直接流入 + 端，不影響輸出。抵銷方法：在 + 端串入電阻 R1‖R2，使 IB1 在 + 端產生 −IB1(R1‖R2) 的修正電壓。只要 IB1 = IB2，修正量會隨電晶體 β 的製程變異同步變化，輸出誤差保持為零。

積分器中，IB2 流入 C1 被持續積分，輸出以 IB2/C1 的斜率漂移；在 + 端串入與 R1 相等的電阻可抵銷此項，但偏移電壓等其他誤差仍會使輸出最終飽和。

例題 8.6
兩級非反相放大器串接，每級增益 100，op amp 的 Vos = 2 mV，輸出擺幅 ±5 V。輸入為零時第二級輸出為何？
  • 第一級輸出偏移：100 × 2 mV = 0.2 V。
  • 第二級輸入為 0.2 V（加上本身 2 mV），輸出 ≈ 100 × 0.202 = 20.2 V，超過 ±5 V，第二級飽和。
  • 多級放大器需要在級間加耦合電容或偏移校正，否則有用信號無法被放大。
練習 8.5
（計算）非反相放大器 R1 = 100 kΩ、R2 = 10 kΩ，IB1 = IB2 = 0.5 µA。求輸入為零時的輸出誤差，以及抵銷電阻值。
  1. Vout = R1IB2 = 100 kΩ × 0.5 µA = 50 mV。
  2. 抵銷電阻 = R1‖R2 = 100 × 10/110 ≈ 9.09 kΩ，串在 + 端。
（計算）積分器 C1 = 1 nF，IB2 = 100 nA、無抵銷電阻。輸出漂移到 10 V 需要多久？
  1. 漂移斜率 = IB2/C1 = 100 V/s。
  2. t = 10/100 = 0.1 s。

8.6非理想效應：頻寬、迴轉率與輸出電阻

1　頻率響應的三個頻段

電容與電感的阻抗隨頻率改變，使增益隨頻率變化。以 R1、C1 低通分壓為例，Vout/Vin = 1/(1 + R1C1s)，在 ω−3dB = 1/(R1C1) 時幅度降為 1/√2。放大器的頻率響應通常分成三段：

  • 低頻段：耦合電容與旁路電容的阻抗變大，增益下降。
  • 中頻段（midband）：所有電容的影響可忽略，增益與相位（0° 或 180°）為定值。
  • 高頻段：電晶體內部電容使增益下降。

2　增益頻寬積

op amp 內部電容使開迴路增益從某個頻率開始下降，常以單極點模型描述：

A(s) = A01 + s/ω1

ω1 為開迴路 −3 dB 頻寬；增益降到 1 的頻率 ωu ≈ A0ω1 稱為單位增益頻寬（unity-gain bandwidth）。非反相放大器代入 A(s) 得閉迴路極點

ωp,closed = ω1(1 + A0R2R1 + R2) ≈ A0ω11 + R1/R2

閉迴路增益乘以閉迴路頻寬約等於 A0ω1：負回授以降低低頻增益換取更寬的頻寬。

3　迴轉率

大信號輸入時，op amp 內部以有限電流對電容充電，輸出變化率有上限，稱為迴轉率（slew rate, SR）：SR = max|dVout/dt|。小信號時輸入加倍、輸出斜率也加倍（線性）；輸出要求的斜率超過 SR 後，輸出改以固定斜率上升，稱為迴轉（slewing），此時輸出不再是輸入的線性函數，建立時間（settling time）也比只受閉迴路時間常數限制時更長。

輸出為 V0 sin ωt 時最大斜率為 ωV0。輸出以最大擺幅 (Vmax − Vmin)/2 為振幅仍不迴轉的最高頻率稱為全功率頻寬（full-power bandwidth）：

ωFP = SR(Vmax − Vmin)/2

4　輸出電阻

實際 op amp 的輸出電阻 Rout 不為零。反相放大器中，Rout 與回授電阻 R1 形成分壓，近似等效於把開迴路增益降為 A0R1/(R1 + Rout)（Rout ≪ R1 時），因而增大增益誤差。R1 越小（或負載越重），此效應越明顯。

5　CMRR 與 PSRR

實際 op amp 的輸出同時受差模輸入、共模輸入與電源變動影響：Vout = AdVid + ACMVCM + AvddVdd + AvssVss。

  • 共模拒斥比（common-mode rejection ratio）：CMRR = Ad/ACM。
  • 電源拒斥比（power-supply rejection ratio）：PSRR+ = Ad/Avdd、PSRR− = Ad/Avss。

兩者皆越大越好，通常以 dB 表示。

例題 8.7
op amp 的 A0 = 105、f1 = 10 Hz、SR = 0.5 V/µs、輸出擺幅 ±10 V。(a) 增益 10 的非反相放大器頻寬為何？(b) 全功率頻寬為何？
  • (a) fu = A0f1 = 1 MHz；fp,closed = 10 × (1 + 105/10) ≈ 100 kHz。
  • (b) ωFP = 0.5 × 106/10 = 5 × 104 rad/s，fFP ≈ 7.96 kHz。
  • 小信號頻寬達 100 kHz，滿擺幅輸出卻在 8 kHz 以上就開始迴轉：大信號應用要同時檢查兩項限制。
練習 8.6
（計算）Ad = 104、ACM = 0.1，CMRR 以 dB 表示為多少？
  1. CMRR = 104/0.1 = 105。
  2. 20 log 105 = 100 dB。
（是非）加上負回授後放大器的增益與頻寬都會增加。
  1. ✗。頻寬增加，但低頻增益由 A0 降為約 1 + R1/R2；兩者乘積約維持 A0ω1。

B　常見陷阱

易錯處
  1. 虛短路的前提：只有負回授且未飽和時成立；比較器、正回授電路不能用。
  2. 虛接地沒有電流流入 op amp：反相端電壓為零，但流過 R2 的電流全部轉向流過 R1。
  3. 電阻命名：本章（Razavi）非反相與反相放大器的回授電阻都叫 R1，增益分別為 1 + R1/R2 與 −R1/R2；其他教材常把回授電阻稱為 R2 或 Rf。
  4. 增益誤差與閉迴路增益成正比：高增益組態對 A0 的要求更高。
  5. 積分器的直流：理想積分器對直流增益無窮大，偏移與偏壓電流都會使其飽和，需要並聯電阻或週期性重置。
  6. 小信號頻寬與全功率頻寬不同：前者由增益頻寬積決定，後者由迴轉率與輸出振幅決定。

C　自我測驗

1. 非反相放大器 R1 = 99 kΩ、R2 = 1 kΩ、A0 = 104，相對增益誤差約為多少？(1 + 99)/104 = 1%。實際增益 = 1/(0.01 + 0.0001) ≈ 99.0。
2. 為什麼反相放大器的輸入阻抗等於 R2？反相端為虛接地，輸入電流 = Vin/R2，所以 Vin/Iin = R2。
3. 積分器 R1 = 100 kΩ、C1 = 0.1 µF，輸入 −0.5 V 直流，1 ms 後輸出變化多少？R1C1 = 10 ms；ΔVout = −(−0.5)(1 ms)/(10 ms) = +0.05 V。
4. （是非）非反相組態把 R1 換成電容即可得到理想積分器。✗。增益為 1 + Z1/Z2，多出的 1 使其無法成為理想積分器。
5. 儀表放大器相對於差動放大器解決了什麼問題？差動放大器的輸入阻抗與增益（R2/R1）互相牽制；儀表放大器在輸入端加緩衝級，使輸入阻抗極高而增益仍由後級電阻比設定。
6. fu = 1 MHz 的 op amp 做增益 50 的非反相放大器，頻寬約為多少？fu/G = 1 MHz/50 = 20 kHz。
7. SR = 1 V/µs，要以振幅 5 V 輸出正弦波而不迴轉，最高頻率為何？ω = SR/V0 = 106/5 = 2 × 105 rad/s，f ≈ 31.8 kHz。
8. 非反相放大器的偏壓電流抵銷電阻為何是 R1‖R2？Vin = 0 時 − 端看到的直流電阻為 R1‖R2（輸出端為低阻抗電壓源，輸入為零時其電壓近似為零）。+ 端串入相同電阻，IB1 = IB2 時兩端的壓降相同，差模誤差為零。
